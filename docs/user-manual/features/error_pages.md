# Friendly Error Pages (404 and 500)

CarpoolCampus provides clear, user-friendly error pages when something goes wrong or when a requested page cannot be found.

---

## Page Not Found (404)

If you navigate to a web address that does not exist or follow a link to a deleted page, CarpoolCampus displays a 404 error page.

### How to navigate back from a 404 error:

1. Look for the **Page not found** notification screen.
2. Click the **Return to Home** button.
3. You will be redirected to the main home page (`/`), where you can continue navigating the site.

---

## Server Error (500)

If CarpoolCampus encounters an unexpected problem while processing your request, a 500 internal server error page is shown instead of a confusing technical error screen.

### What to do when encountering a 500 error:

1. Read the on-screen message notifying you that something went wrong.
2. Click the **Return to Home** button to safely navigate back to the home page (`/`).
3. If the problem persists, try logging out and logging back in, or contact your campus carpool administrator.
