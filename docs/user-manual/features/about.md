# About & Privacy Summary Guide

This guide explains how to view CarpoolCampus background information, understand who can use the platform, learn how ride matching works, and review data privacy safeguards.

## Overview

The **About** page provides transparent details on:
- Who CarpoolCampus is built for (students, faculty, and campus staff).
- How matching works in plain language based on campus schedules and general locations.
- What personal data is collected and how location privacy is protected using Forward Sortation Areas (the first 3 characters of Canadian postal codes).

## How to Access the About Page

Follow these steps in your browser:

1. Open your web browser and navigate to the CarpoolCampus home page (e.g., `http://localhost:8000/`).
2. In the top navigation bar, locate and click the **About** link.
3. Alternatively, visit the URL directly by entering `/about/` in your browser address bar.
4. Review the information sections:
   - **Who CarpoolCampus Is For**: Learn about institutional affiliation and domain-based access.
   - **How Matching Works**: Understand schedule overlap and route matching without GPS tracking.
   - **Privacy & Your Data**: Read about the 3-character postal code privacy safeguard and how data is isolated within your campus community.

## Demo Login

The About page is public and does not require an active account or sign-in. Anyone can view it prior to creating an account or joining an organization.
