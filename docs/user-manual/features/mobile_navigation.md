# Mobile Navigation Menu

The mobile navigation menu allows users browsing CarpoolCampus on smaller screens (such as smartphones or tablets) to access navigation links cleanly without cluttering the screen.

## Using the Mobile Navigation Menu

1. **Open the Site on a Small Screen**:
   Visit CarpoolCampus using a mobile device browser or resize your desktop browser window to a narrow width.

2. **Locate the Menu Button**:
   In the top header area to the right of the CarpoolCampus logo, click or tap the hamburger menu icon button (three horizontal lines).

3. **Toggle the Navigation Links**:
   - Tapping the button expands the menu, displaying navigation links such as **About** and account details.
   - Tapping the button again collapses the menu, hiding the links to free up screen space.

## Accessibility Support

- The mobile menu button updates its `aria-expanded` status automatically when opened or closed.
- Screen readers announce the expanded or collapsed state of the menu control (`mobile-menu-button`) associated with `mobile-menu`.
